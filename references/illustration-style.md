# 插图风格指南（Illustration Style Guide）

本文件定义"手机随手拍"美学的详细规则。所有图片提示词必须遵循这套视觉语言，保证系列插图的风格一致性。

---

## 核心美学："不该拍但忍不住拍了"

每张图都是一个叙事者（或邻居、路人）用廉价手机在某个瞬间犹豫着按下快门的结果。不是为了记录，不是为了发朋友圈，是一种说不清的冲动——拍完可能就锁屏放回口袋了。

这意味着：
- 构图永远是仓促的、歪的、来不及的
- 对焦永远对错了地方
- 画面里总有不该出现的东西（拍摄者的手指、衣袖、鞋尖）
- 技术质量极差（噪点、模糊、压缩）
- 但画面里有一个东西是对的——那个让人忍不住举起手机的瞬间

---

## 提示词三段式结构

每张图的提示词由三部分组成：

### 第一段：场景描写

极度具体的物理细节。写法规则：

1. **从主体开始**，然后向外扩展到环境
2. **每个物件都要有状态**：不是"一个瓶子"，是"一个被脚踩扁的农夫山泉矿泉水瓶，标签还在但皱了"
3. **人物只写身体**：姿态、衣着、体型、局部特征（纹身、耳钉、骨节）。绝不写表情、绝不写正脸
4. **光源必须明确**：几个光源、什么色温、照亮了什么、什么在阴影里
5. **地面细节**：积水、烟头、菜叶、广告纸、鞋印——地面是城中村最诚实的叙述者
6. **墙面细节**：水渍、剥落的腻子、小广告、蹭痕、手写的油漆字
7. **声音转视觉**：照片拍不到声音，但可以写"虽然照片里听不到"然后描述声音的视觉线索
8. **气味转视觉**：同理，用可见的线索暗示气味（油渍、烟雾、菜叶发酵的颜色）

### 第二段：拍摄技术描写

模拟廉价安卓手机的全部技术特征：

| 参数 | 规则 |
|------|------|
| 构图倾斜 | 5-20度，标注具体角度和方向 |
| 对焦错误 | 对焦点锁在非主体上（扶手、地砖、前景杂物），主体柔焦 |
| 运动模糊 | 拍摄者手抖 + 被摄体在动，标注哪里有拖影 |
| ISO/噪点 | 暗光场景 ISO 拉到极高，暗部红绿色块噪点 |
| 白平衡 | 永远失败——混合光源下偏青绿或偏黄，标注具体偏移方向 |
| 曝光 | 被天空/灯光骗了，人物欠曝或过曝 |
| JPEG压缩 | 色阶断裂、马赛克色块，尤其在暗部和高光交界处 |
| 镜头入侵 | 拍摄者的手指/衣袖/鞋尖/门框出现在画面边缘 |
| 镜头脏污 | 雨滴、指纹、水汽，形成半透明斑点 |
| 景深 | 廉价手机的景深很浅或很深（取决于距离），标注清晰区和模糊区 |

必须标注的元数据：
- 拍摄视角描述（"从四楼往下拍""街对面七八米远""门缝里伸出手机"）
- 拍摄者的心理暗示（"犹豫的""来不及的""拍完就后悔的"）
- 设备（"廉价安卓手机"）
- 故事内时间（"2018 冬，十二月"）
- "非摆拍"标注

### 第三段：负面提示词（Negative Prompts）

必须包含的基础负面词：
```
professional photography, dslr, studio lighting, clear face, front-facing, portrait, well-lit, sharp focus on subject, posed, cinematic, model, eye contact with camera
```

根据场景追加的负面词：
- 室内场景：`modern interior, clean, well-maintained`
- 人物场景：`glamour, fashion, high heels, makeup tutorial, influencer, ring light`
- 街道场景：`clean street, blue sky, golden hour, beautiful composition`
- 情绪场景：`romantic, hopeful, warm lighting, dramatic lighting`
- 建筑场景：`architectural photography, drone shot, hdr, vivid colors`

## 人物视觉规则

### 绝对不露正脸

所有人物只能以以下方式出现：
- 背影（最常用）
- 侧影（只露下颌线、耳朵轮廓）
- 剪影（逆光，只有轮廓）
- 局部（手、脚、后脑勺、肩膀、颈椎骨）
- 被遮挡（头发遮脸、帽子、低头、转身）

### 精神小妹的视觉特征

- 瘦，胳膊像竹竿，锁骨突出，颈椎骨可见
- 染发（奶茶棕、浅棕、深棕偏红），黑色发根长出来
- 纹身（字母、星星、小图案，位置：锁骨下、后颈、手腕）
- 耳饰（大圆环耳环、银色圆环耳钉）
- 穿着：紧身吊带/露脐T/短款外套 + 破洞牛仔短裤/紧身牛仔裤
- 鞋：厚底老爹鞋或白色帆布鞋，绝不穿高跟鞋
- 指甲：长的、尖的、深色甲油
- 配饰：亮粉色小挎包、红色编织手绳

### 老高的视觉特征

- 前期：灰白短发梳得整齐，深蓝色长袖衬衫（熨过的），深灰色西裤（裤线还在），黑色皮鞋（擦过的）。在这栋楼里完全不搭
- 后期：头发长了没梳，贴在额头上；胡子没刮；外套明显大了肩膀撑不起来；皮鞋不再发亮蒙了灰

### 陈砚的视觉特征

- 极瘦，骨节突出
- 短发极短（化疗后新长的，像青皮）
- 穿着：黑色宽松T恤/黑色长款羽绒服，简单朴素
- 鞋：黑色运动鞋
- 行李箱（离别场景）：黑色硬壳，万向轮沾泥

## 环境视觉词库

### 楼道/楼梯

水泥台阶边缘磨圆、绿漆铁管扶手大面积剥落露铁锈、白漆墙壁发灰发黄、水渍线、小广告（开锁/疏通/搬家）、声控节能灯管（惨白偏冷偏蓝）、红色塑料绳缠在扶手上、蜘蛛网、烟头散落在裂缝里

### 楼外/街道

九十年代瓷砖外墙发黄脱落、空调外机歪斜、电线缠成乱麻、黄色油漆手写"出租房 拎包入住"、电瓶车、共享单车倒在墙边、积水反光、菜叶烂纸壳、卷帘门喷"禁止停车"

### 集市/商铺

红底黄字招牌、绿底白字招牌、塑料布菜摊、铁皮棚、油渍地面、塑料桶、蓝色三轮车、红色遮阳伞、钠灯偏暖黄

### 光线色温对照

| 光源 | 色温 | 在画面中的表现 |
|------|------|----------------|
| 楼道节能灯 | 冷白偏蓝/偏绿 | 人脸发青，衣服饱和度被吃掉 |
| 钠灯路灯 | 暖黄偏橙 | 积水反射成模糊的橙色光晕 |
| 手机屏幕 | 冷白 | 照亮面前一小块墙壁/下巴 |
| 烟头 | 橘红 | 画面里最小但最醒目的光点 |
| 便利店招牌 | 白+红 | 最大面积光源，形成剪影效果 |
| 清晨阴天 | 灰蓝偏冷 | 一切蒙着一层青灰色 |
| 傍晚阴天 | 铅灰 | 没有方向感的平光 |

## 情绪功能分类

每张图应该承担一个明确的叙事功能：

| 类型 | 功能 | 示例 |
|------|------|------|
| 日常质感 | 建立世界的物理真实感 | 楼梯口的瓶子、下楼出门的背影 |
| 关系锚点 | 标记两人关系的某个瞬间 | 便利店屋檐下的香槟、楼梯转角两人坐着 |
| 情绪高潮 | 承载某个节点的情绪重量 | 雨天三楼的门、最后一天她走进楼洞 |
| 人物肖像 | 建立人物的视觉印象 | 老高初见（衬衫皮鞋）、老高最后一面（瘦了乱了） |
| 时间标记 | 标记故事的时间流逝 | 高铁窗外的拆迁（多年后） |
| 危机场景 | 承载具体事件的紧张感 | 医院走廊、小区门口的电瓶车 |

## 输出模板

```markdown
## [编号]. [标题]（[叙事节点简述]）

[场景描写：500-800字，极度具体的物理细节]

[拍摄技术描写：200-400字，模拟廉价手机的全部技术瑕疵]

负面建议：[逗号分隔的英文负面提示词]
```

## 自检清单

生成提示词后检查：

- [ ] 没有任何人物露出正脸
- [ ] 构图歪斜角度已标注
- [ ] 对焦点不在主体人物上
- [ ] 至少标注了两种技术瑕疵（噪点、模糊、压缩、白平衡）
- [ ] 光源数量和色温已明确
- [ ] 地面细节至少三项
- [ ] 拍摄者视角和心理已描述
- [ ] 故事内时间已标注
- [ ] 负面提示词包含基础必选项
- [ ] 与已有提示词的视觉风格一致（同一栋楼的物理细节不矛盾）
