# 去AI味检查清单（叙事专用版）

本清单专门针对中文非虚构叙事文体。基于 chinese-humanizer 的 Pattern Taxonomy，但去掉了议论文/分析文章的项目，加入叙事文体专用的检查。

---

## 第一优先级：结构层（最致命）

### 1. 逐句分段

**症状：** 几乎每句话独占一段。段落长度高度均匀（每段 1-2 句）。

**检测：**
- 段落数 / 句号数的比值是否接近 1:1
- 是否有连续超过 5 段都是单句段
- 否定动作是否独占一段（"我没说话。"）
- 对话是否每句"我说""他说"都独立成段，即使是快速一问一答

**修复：归拢**
- 同一时间、同一场景、同一情绪流的句子合并为一段
- 只在以下情况换段：时间跳转、注意力转移、情绪变化、场景切换
- 简短一问一答可以合并到同一段，不必每句独立成行

### 2. 段内句号过密

**症状：** 段落已归拢，但段内连续短句仍用句号断开。

**检测：**
- 段内连续 3 个以上短句（<15 字）用句号分隔
- 这些短句描述的是同一瞬间的连续动作或感知
- 之间没有时间间隔或注意力切换

**修复：逗号替代**
- 同一瞬间的动作/感知之间用逗号
- 判断标准：这两个分句之间，注意力有没有移开？没有→逗号；有→句号
- 例：`我下意识扶住门框。门框是凉的。我看见我的手在抖。` → `我下意识扶住门框，门框是凉的，我看见我的手在抖。`

### 保留的短句独段

以下情况不需归拢，是有意为之的节奏选择：
- 重锤效果的关键句（"那是我最后一次见他。"）
- 数字/三字短语作为段落（"39.4。""三个字。"）
- 章节末尾的留白句

## 第二优先级：词汇层

### 3. 大词提升（Big-Word Lift）

**症状词：** 真正、关键、核心、本质、结构、能力、时代、系统、认知、方法论、底层逻辑、范式、路径、抓手

**失败模式：** 具体场景被提升为抽象分析，读者还没感受到事情就被告诉它的意义。

**修复：** 让概念在具体物件、动作、冲突或例子之后才出现。叙事文体里，绝大多数情况下这些词都该删掉，让画面自己说话。

### 4. 固定句式模板

**症状词：** 不是……而是……、不只是……更是……、一方面……另一方面……、既……又……、从……到……、如果说……那么……、当……时……

**失败模式：** 文字像在往现成模具里灌内容。

**修复：** 一段里最多保留一个最强的模板句。其余拆散为口语化、问句、或场景化的过渡。

### 5. 总结反射（Summary Reflex）

**症状词：** 这就是、问题在于、更重要的是、归根到底、本质上、真正的问题是、这能解释、这意味着、由此可见

**失败模式：** 叙述者一直在替读者收尾。叙事文体里基本不该出现这类总结。

**修复：** 删掉总结句。如果觉得删了之后段落不完整，说明前面的场景写得不够具体——回去补场景，而不是补结论。

### 6. 三连排比（Rule-of-Three）

**症状：** 三个平衡的并列项，如"订单少了，利润薄了，账期还在拖""岗位会变、公司会变、行业会变""走得快，堆得乱，催得急"。

**失败模式：** 压力被陈列在整齐的展示架上。

**修复：** 打破对称。用一个具体细节加一个后果代替三个泛泛的并列项。

## 第三优先级：叙事层（叙事文体专用）

### 7. 视角越界

**症状：** 写了叙述者当时不知道的事，或猜测他人内心。

**检测：**
- "她大概是……""他其实……""她心里想……"
- "我后来才明白她……""她那时一定……"
- "他没说，但我知道……""她不想让我看到……"

**修复：** 参照 [视角纪律](pov-discipline.md)。改为可观察的动作、表情、对话，或承认不知道。

### 8. 情绪外溢

**症状：** 叙述者直接告诉读者人物的情绪状态。

**检测：**
- 直接命名情绪：孤独、绝望、痛苦、愤怒、悲伤
- 用形容词总结心理状态：他很无力、她很迷茫
- 用比喻描述情绪：心像被刀割

**修复：** 把情绪改为身体动作或物理细节。"绝望"→"跪在地上没抬头"。"孤独"→"电视开着，声音很小"。

### 9. 设计感过强的对比

**症状：** 高度配对的句式，如"手里摸到的……耳朵里听到的……""一边……一边……""这边……那边……"。

**失败模式：** 句子在炫耀自己的结构。

**修复：** 把对比拆松。一句平实的观察，加它带出的矛盾。例：
- 设计感强：`手里摸到的，是一个会聊天的工具。耳朵里听到的，却是岗位会变。`
- 平实：`自己试的时候就是问问问题。可一转头，外面又都在说要变天。`

### 10. 顿悟式台词与心理

**症状词：** 第一次清楚地意识到、终于明白、过去那套办法开始失灵、这一刻他认识到

**失败模式：** 人物突然替文章演讲主题。剧本式写法，对真实人物的侮辱。

**修复：** 用不确定代替顿悟。让人犹豫、失败、误判、感觉不对劲。绝对不让人物在死前说"活着真没意思"这类台词。

### 11. 预言式回望

**症状词：** 这是最后一次、我那时还不知道、多年后我才明白、谁也想不到

**失败模式：** 用未来的全知视角给当下的场景贴标签。

**修复：** 删掉预言。让具体场景自己承担分量。叙述者已经知道结局，但本篇里这件事就让它淡淡发生过去。

### 12. 救赎/觉醒/俯视

**症状：**
- 让人物因为遇见某人而"成长""觉醒""走出来"
- 让叙述者站在更高位置评价底层人物的处境
- 用抒情方式写苦难，把苦难美化为某种意义

**修复：** 删掉。这是黑名单铁律。她饿肚子，她做违法的事，她被骗，她也开心，她也活着。这些都不能少，也不能多。

## 硬扫描命令

写完后用 ripgrep 扫描以下模式（在 Windows 下用 `rg` 或 grep 工具）：

```bash
# 大词与固定句式
rg -n "真正|关键|核心|本质|结构|能力|时代|系统|认知|方法论|不是.*而是|一方面.*另一方面|既.*又|从.*到|如果说.*那么|这就是|问题在于|更重要|归根到底|这意味着|由此可见|也正因如此" <file>

# 视角越界
rg -n "大概是|其实是|心里想|后来才明白|那时一定|他没说.*但我知道|不想让我看到|是为了" <file>

# 顿悟与预言
rg -n "第一次.*意识到|终于明白|这是最后|那时还不知道|多年后才|谁也想不到" <file>
```

段落原子化扫描（PowerShell/bash 兼容）：

```bash
# 段落与句号比，接近 1:1 即报警
awk 'BEGIN{p=1} /^$/{p++} {gsub(/[^。]/,""); s+=length} END{printf "paragraphs: %d, sentences: %d, ratio: %.2f\n", p, s, p/s}' <file>
```

## 软指标（人工通读）

扫描通过后仍需人工通读检查：

- **句长分布**：是否都是中等长度的句子？真人写作有长有短，AI 倾向中长均匀
- **逗号/句号比**：叙事段落里逗号应该明显多于句号
- **形容词密度**：每 100 字超过 3 个形容词就过密
- **对话节奏**：快速对话是否被均匀切段，破坏了节奏
- **物件密度**：每段是否至少有一个具体的、可见的物件或动作
- **回望句数量**：全篇统计，超过十处需要砍

---

## 接受标准

修订后的段落通过以下全部检查才算合格：

1. 段落:句号比远低于 1:1
2. 段内同瞬间的连续短句用逗号连接
3. 没有未经场景支撑的大词
4. 没有重复堆叠的固定句式
5. 没有视角越界（猜测他人内心）
6. 没有情绪外溢（直接命名情绪）
7. 没有顿悟式台词或预言式回望
8. 没有救赎/觉醒/俯视的痕迹
9. 事实内容、人物关系、情节顺序未改动
