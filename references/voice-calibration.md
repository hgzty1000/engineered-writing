# 语感校准（Voice Calibration）

本文件定义写作时的语感规则。三个参照系有明确的使用边界和优先级。

---

## 主调：余华

适用范围：全篇叙述层的默认声调。

### 句法规则

- 短句为主，主谓宾结构干净
- 一个句子只做一件事：一个动作、一个观察、一个事实
- 不堆叠从句，不用"虽然……但是……因为……所以……"的复合结构
- 逗号连接同一口气内的连续动作；句号标记注意力切换或时间跳跃

### 修辞规则

- 几乎不用形容词。如果非用不可，用最朴素的那个（"大""小""旧""破"）
- 不用比喻。不说"像什么"。事物就是它自己
- 不用排比。不用对仗。不追求句式的对称美感
- 不用感叹号（叙述层）。对话里可以有，但叙述者永远平静

### 情绪规则

- 情绪藏在事实背后。叙述者从不替读者总结"这很悲伤""这很荒诞"
- 一个具体的、看似无关的物件或动作承担整段的重量
- 黑色的东西用平静的语气讲，平静的东西用平静的语气讲——温度恒定
- 叙述者的情绪只通过选择讲什么、不讲什么来体现

### 对话规则

- 不加引号。对话用"我说""他说""小雨说"领起
- 对话独立成行（但快速一问一答可以合并）
- 叙述者（陈砚）自己说的话保持普通话短句
- 其他人物的话保留原样：黑话、脏话、方言口音、语病

### 余华式的具体示范

好的：
```
那把青菜在我屋里放了三天才吃完。
```

不好的：
```
那把青菜承载着某种我说不清的情感，在我屋里放了三天，每次看到它我都会想起她。
```

好的：
```
老高坐在楼梯转角，手里夹着烟，看见我点了一下头。
```

不好的：
```
老高孤独地坐在昏暗的楼梯转角，手指间夹着一根快要燃尽的烟，看见我后疲惫地点了一下头。
```

## 辅调：史铁生

适用范围：全篇不超过 2-3 段。出现在某件事过去之后的下一段，作为短暂停顿。

### 使用条件

- 必须在一个具体场景结束之后才能出现
- 形式：克制的、不下结论的自问自答
- 长度：3-5 句，绝不超过一段
- 不能变成哲学随笔或人生感悟

### 允许的形式

```
我后来想了很多年，也没想明白那天晚上他为什么坐在那里。可能他也没有为什么。有些事情就是没有为什么的。
```

### 不允许的形式

```
那一刻我突然理解了孤独的本质——它不是没有人陪伴，而是即使有人在身边，你们之间的距离也无法被任何语言跨越。这种存在主义式的困境……
```

### 警戒线

- 史铁生的调子用多了，陈砚会显得太"懂"。他最好是没想清楚的
- 如果一段回望超过 5 句，砍掉
- 如果回望里出现了结论性判断，删掉结论，保留疑问

## 局部允许：莫言式感官饱和

适用范围：仅限以下三类场景，全篇不超过 3 处。

### 允许使用的场景

1. 楼下集市的具体画面（菜叶发酵的酸气、肉摊的血水、夏天暴雨打在铁皮棚上）
2. 五楼姐妹群租房闹翻的那一夜
3. 极少数需要把感官推到顶的瞬间（如医院走廊、暴雨夜）

### 规则

- 感官细节必须具体到可以闻到/听到/摸到，不能是"嘈杂""混乱"这种概括
- 可以密集堆叠细节，但每个细节必须是真实的、物理的
- 不能用于人物心理描写——只用于环境和身体感受
- 用完立刻回到余华的平静调子，不能让感官饱和蔓延

### 不允许使用的场景

- 日常对话场景
- 陈砚独处时的内心
- 任何需要"安静"的段落
- 江浙城中村的现代质感扛不住莫言式的乡土爆破力——不能全篇使用

---

## 叙述层 vs 场景层的温差

核心原则：叙述者（陈砚）冷，但场景该闹就闹。

- 读者跟着一个安静的人走进一个吵闹的世界——这个温差本身是能量来源
- 绝不能让陈砚的冷把姐妹们的喧闹压死
- 姐妹们说话时，节奏可以快、可以乱、可以叠加
- 陈砚的叙述恢复后，立刻回到短句和平静

---

## 回望句预算

全篇不超过十处。每一句都贵。

### 允许的形式

- 一句，不解释，不展开
- 例：`那是她第一次叫我哥。后来她叫了很多次。`
- 例：`那把青菜在我屋里放了三天才吃完。`

### 不允许的形式

- "这是最后一次……"（预言）
- "我那时还不知道……"（钩子）
- "多年后我才明白……"（替读者总结）
- 连续两句回望（一句就够）

### 使用原则

- 回望句是叙述者唯一允许情绪外溢的地方
- 它的力量来自克制——前后都是平静的叙述，中间突然一句带着时间重量的话
- 如果一段里已经有了足够的情绪密度，不需要回望句
