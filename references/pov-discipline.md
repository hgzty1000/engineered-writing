# 视角纪律（POV Discipline）

严格外部视角：陈砚只写他看到、听到、知道的事。不猜测任何人的内心。

---

## 核心规则

叙述者是回忆中的"我"。他只能报告：
1. 他当时亲眼看到的（动作、表情、物件、环境）
2. 他当时亲耳听到的（对话、声音、别人转述的话）
3. 他自己的身体感受（冷、饿、咳嗽、心跳）
4. 他自己承认不确定的感受（"我不知道为什么""我说不清"）

他不能报告：
1. 任何他人的内心活动
2. 他不在场时发生的事（除非有人告诉他）
3. 他当时不知道的信息（即使叙述者现在知道了）
4. 对他人行为动机的推测

---

## 禁止句式（硬性红线）

以下句式一旦出现，视角即被破坏：

| 禁止 | 原因 |
|------|------|
| 她大概是…… | 猜测他人内心 |
| 他其实…… | 暗示叙述者知道对方的真实想法 |
| 她心里想…… | 直接进入他人意识 |
| 我后来才明白她…… | 回溯式替他人解释动机 |
| 她那时一定…… | 推测 |
| 他没说，但我知道…… | 越界的"读心" |
| 她不想让我看到…… | 猜测他人意图 |
| 他是为了…… | 替他人解释行为原因 |

---

## 允许句式

| 允许 | 原因 |
|------|------|
| 我不知道她为什么…… | 承认无知 |
| 她看了我一眼 | 描写可观察的动作 |
| 他的手在抖 | 描写可观察的身体状态 |
| 她说…… | 记录对话 |
| 张姐后来告诉我…… | 信息来源明确 |
| 我那时不知道为什么 | 叙述者自己的困惑 |
| 她笑了一下，没说话 | 动作+留白 |
| 我看见他眼睛红了 | 可观察的生理反应 |

## 常见违规场景及修复

### 场景1：想解释小雨为什么不和陈砚发生关系

违规写法：
```
她大概是把我当成了一块自留地——在她的交易系统之外，单独留出来的一个不能被消费的位置。
```

正确写法：
```
有一次她喝多了，靠在我肩膀上，过了一会儿又坐直了。她说，你别碰我。我说我没碰你。她说，我知道。
```

原则：让读者从行为中自己拼出"自留地"的含义。叙述者不下结论。

### 场景2：想表达老高的孤独

违规写法：
```
老高其实很孤独。他每天一个人坐在三楼，没有人来找他，也没有地方可去。
```

正确写法：
```
老高的门经常开着。我路过的时候能看见他坐在床边，电视开着，声音很小。有时候他在看，有时候没在看。
```

原则：只描写陈砚路过时看到的画面。"孤独"由读者自己感受。

### 场景3：想写王建国的绝望

违规写法：
```
王建国那一刻彻底绝望了。他觉得自己这辈子就这样了，再怎么努力也爬不出来。
```

正确写法：
```
王建国跪在地上，膝盖磕在水泥地上的声音我在三楼都听见了。他没抬头。那个人走了之后他还跪着，过了很久才慢慢撑起来，腰是弯的，颤的。
```

原则：绝望通过身体动作和物理细节传达，不通过心理描写。

### 场景4：想写姐妹们的处境

违规写法：
```
她们每个人都有自己的故事，都是被生活逼到这一步的。她们并不想这样，只是没有别的选择。
```

正确写法：
```
苗苗有一次跟我说，她老家还有个弟弟在读高中。她说这话的时候在涂指甲油，头都没抬。
```

原则：不替她们总结处境，让一个具体的细节承担重量。

## "全楼档案管理员"陷阱

叙述者不是一个全知的观察者。他不会像写报告一样介绍每个邻居：

违规写法：
```
二楼住着王建国一家，安徽阜阳人，在附近工厂打工。三楼是老高，五十出头，独居，以前好像做过什么生意。
```

正确写法：
```
我搬进去的时候，二楼那家人的小孩在楼道里跑。后来我才知道那个男的姓王，在哪里上班我不清楚，反正每天很早出门。
```

原则：信息是逐渐、零散、不完整地获得的。陈砚不是在做住户调查。

---

## 信息获取的合法渠道

陈砚可以通过以下方式获得关于他人的信息：

1. **直接观察**：他亲眼看到的动作、外貌、物件
2. **对话**：别人直接告诉他的（标注信息来源："张姐说""小雨跟我讲"）
3. **偶然听到**：楼道里的声音、隔壁的吵架声、楼下的喊叫
4. **推断但标注不确定**："好像是""大概""我不确定"——但这只能用于事实推断，不能用于心理推断
5. **事后得知**：别人后来告诉他的（"后来张姐跟我说那天……"）

不合法的渠道：
- 叙述者"就是知道"（没有信息来源）
- 从他人的表情直接跳到他人的想法
- 用"显然""明显"来伪装推测为事实

---

## 与回望的关系

回望句（"后来她叫了很多次"）不违反视角纪律，因为它报告的是叙述者自己后来经历的事实。但回望不能用来补充当时不知道的他人信息：

允许：`那是我最后一次在那栋楼里见到他。`（叙述者自己的经历）

不允许：`我后来才知道，那天晚上她其实哭了一整夜。`（除非有人明确告诉他）

---

## 自检方法

写完一段后，逐句问自己：

1. 这个信息，陈砚当时是怎么知道的？
2. 如果答案是"他就是知道"——删掉或改为可观察的描写
3. 如果答案是"别人告诉他的"——标注信息来源
4. 如果答案是"他猜的"——要么删掉，要么改为"我不知道为什么"
