# 修订模式（Revise）

按 `engineered-writing` skill 的 C 模式执行。

## 工作流

目标：$ARGUMENTS

1. 读取目标段落/章节
2. 运行诊断（基于 `references/anti-ai-checklist.md`）：
   - **结构层**：逐句分段、段落原子化、段内句号密度
   - **词汇层**：大词提升、固定句式模板、三连排比、总结反射
   - **叙事层**：视角越界、情绪外溢、设计感过强的对比、顿悟式台词
3. 逐段修订：
   - 归拢段落（同一时间/场景/情绪流合并）
   - 逗号替代句号（同一瞬间的连续动作/感知）
   - 大词降级为具体物件/动作
   - 固定句式拆散为口语化表达
   - 保留叙事骨架和所有事实内容不变
4. 输出：before/after 对比 + 修改说明（简短，不写论文）
