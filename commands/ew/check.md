# 跨篇一致性检查（Cross-Check）

按 `engineered-writing` skill 的 D 模式执行。

## 工作流

范围：$ARGUMENTS（默认全部 `*_初稿.md`）

1. 读取所有已有篇章初稿 + `CONTEXT.md` + `人物小传.md` + `修订记录.md`
2. 逐项比对：
   - **时间线**：事件发生顺序、年份、季节、月份是否跨篇一致
   - **人物**：姓名、年龄、籍贯、职业、楼层在各篇中是否矛盾
   - **设定**：铁律是否被某篇违反
   - **物件/空间**：楼层分布、房间描述、物品是否前后矛盾
   - **互文**：同一场景在不同篇中的描写是否对得上（时间、原因、细节）
   - **章节编号**：跨篇连续阅读时编号是否重复或跳跃
3. 输出：冲突清单（格式参照 `修订记录.md`：问题→旧文→新文建议）

## 可选：跑独立脚本

```bash
bash scripts/consistency-check.sh .
```
