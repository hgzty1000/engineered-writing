# 写作模式（Draft）

按 `engineered-writing` skill 的 B 模式执行。

## 工作流

参数：$ARGUMENTS

### 1. 写前回查（必须先做）

自动读取并提取本节相关约束：
- `CONTEXT.md`：铁律、黑名单写法、文风模式、视角模式、语感参照系
- `人物小传.md`：本节出场人物的当前状态、已知信息边界
- `*_写作提示词.md`：本节的场景设计、情绪走向、节奏要求
- 前文（如有）：上一节结尾的状态、未关闭的线索
- `修订记录.md`：已修复的冲突点（避免重蹈）

### 2. 写作

按以下规则输出初稿：
- 语感：参照 `references/voice-modes.md` 中 CONTEXT.md 选定的模式
- 视角：参照 `references/pov-modes.md` 中 CONTEXT.md 选定的模式
- 节奏：段落归拢，逗号连接同一时刻的动作，只在真正的节奏断点换段
- 对话：不加引号，"我说""他说"领起，黑话/脏话/方言原样保留
- 回望句：全篇预算十处，每一句都贵

### 3. 写后自检（四项门禁）

- **视角纪律**：是否写了叙述者当时不知道的事？是否猜测他人内心？
- **去AI味**：逐句分段？句号过密？大词提升？固定句式？三连排比？
- **一致性**：人名、时间线、物理空间、设定是否与 CONTEXT/人物小传冲突？
- **铁律**：是否触犯黑名单写法（救赎、俯视、命名关系、预言式回望）？

### 4. 输出

初稿正文 + 自检报告（仅标注有风险的点，通过的不赘述）
