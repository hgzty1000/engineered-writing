# 场景扩写（Expand）

按 `engineered-writing` skill 的 F 模式执行。

## 工作流

锚点：$ARGUMENTS

1. 读取用户指定的场景锚点（来源：人物小传中的事件、CONTEXT.md 的场景设计、写作提示词中的某段描述）
2. **写前回查**（同 `/ew:write` 第1步，额外关注）：
   - 该场景涉及的所有人物此刻的状态和已知信息边界
   - 该场景在其他篇章中是否被提及（如有，需对齐细节）
   - 该场景前后的叙事节奏（前一段是快是慢？后面接什么？）
3. 按语感参照系展开为完整叙事段落（对话 + 动作 + 环境 + 节奏）
4. **写后自检**（视角/AI味/一致性/铁律 四项）
5. 输出：扩写段落 + 自检报告 + 与前后文的衔接建议
